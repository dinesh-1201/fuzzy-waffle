# Phase 4 — RA-ORB Serious Validation

## Dataset

Cleaned NIFTY 5-minute cash-index OHLC: 2,784 complete sessions from 2015-01-09 through 2026-05-18. No option-chain data and no volume in the source dataset.

## Candidate under test

- First 3 x 5-minute candles define the 15-minute opening range.
- Four consecutive closes outside the opening range confirm the breakout.
- Entry at the confirmation candle close.
- One trade per day.
- Entry window through 11:00.
- Stop = 0.60% of entry.
- Target = 3R.
- Exit at target, stop, or 15:25 close.
- Ambiguous bars use stop-first.
- No weekday filter.
- Narrow opening-range condition: OR width <= approximately 0.2497% of price.

The candidate remains a research hypothesis, not a frozen production strategy.

## 1. Rolling walk-forward

A chronological rolling test was run with approximately 3 years of training followed by 6 months of unseen testing. No future test observations were used to set the training-derived OR threshold.

### Training-derived Q25 threshold per fold

Across 16 non-empty test windows:

- Test trades: 342
- Positive windows: 13 / 16 = 81.25%
- Aggregate test R: +45.30R
- Average fold expectancy: approximately +0.176R/trade
- Average fold win rate: approximately 58.3%
- Mean fold profit factor: approximately 2.14

The result is encouraging, but the fold-level trade counts vary considerably. Several six-month windows contain only a handful of trades, so the 81.25% positive-window figure must not be interpreted as an 81% probability of winning a trade.

### Fixed 0.2497% threshold stress

Using the previously training-derived 0.2497% threshold unchanged across the rolling tests:

- Test trades: 346
- Positive windows: 15 / 17 = 88.24%
- Aggregate test R: +59.69R
- The 2026 YTD window currently contains only 3 trades and was negative.

This fixed-threshold result is useful as a robustness stress, but the threshold itself was originally discovered using earlier training data and therefore is not a completely independent parameter choice.

## 3. Monte Carlo bootstrap

For the 480 trades generated by the 0.2497% candidate, 20,000 bootstrap samples of trade outcomes were generated with replacement.

Bootstrap total-R percentiles:

- 1st: +32.46R
- 5th: +44.18R
- 50th: +73.27R
- 95th: +102.65R
- 99th: +114.89R
- Probability of positive total R in the bootstrap: 100% in this sample.

Bootstrap expectancy percentiles:

- 1st: +0.0676R/trade
- 5th: +0.0920R/trade
- Median: +0.1527R/trade
- 95th: +0.2139R/trade
- 99th: +0.2394R/trade

Bootstrap maximum drawdown percentiles:

- 1st: -3.93R
- 5th: -4.54R
- Median: -6.89R
- 95th: -11.52R
- 99th: -14.55R

Longest losing streak in the bootstrap was 17 trades; median was about 7 and the 95th percentile was about 10.

This is a trade-resampling diagnostic, not a guarantee. It assumes the observed trade outcomes are representative and does not fully capture regime clustering or changing market microstructure.

## 4. Execution-cost stress

Previous index-point slippage stress showed the candidate remained positive at approximately 1, 2, 3 and 5 points of assumed round-trip slippage, with average R per trade approximately:

- 1 point: +0.119R
- 2 points: +0.0938R
- 3 points: +0.0684R
- 5 points: +0.0177R

At 5 points the edge is thin. This is only an index-point slippage stress and is not a complete brokerage, exchange-fee, STT, GST, stamp-duty or options execution model.

## 5. Ambiguous-bar stress

For the candidate sample, the stop-first and target-first interpretations produced the same aggregate result because the candidate trade set did not contain material stop/target same-bar ambiguity affecting the final outcome. We still retain stop-first as the production-safe convention.

## 6. Verdict

### Status: PROMISING, NOT YET PROVEN

The evidence now supports the hypothesis that a four-close NIFTY opening-range breakout performs better when the first 15-minute range is relatively narrow.

What is encouraging:

1. The effect survives chronological walk-forward testing.
2. A broad OR-width plateau remains positive instead of only one optimized threshold working.
3. Bootstrap resampling keeps expectancy positive.
4. The candidate has more execution-cost headroom than the unrestricted baseline.
5. No weekday filter is required.

What is still missing:

1. Historical NIFTY option-chain data with contract-level intraday prices.
2. Bid/ask-aware option execution modelling.
3. Delta, gamma, theta and IV analysis.
4. Realistic brokerage/tax/fee modelling for the intended instrument.
5. Forward paper-trading validation.
6. A completely untouched final holdout period for the final frozen rules.

## Important conclusion

Do not claim an 80% win rate. The strongest defensible result at this stage is a positive-expectancy underlying signal with approximately mid-50s win rate and encouraging robustness. The next decisive gate is whether the edge survives when translated into actual NIFTY option premiums.
